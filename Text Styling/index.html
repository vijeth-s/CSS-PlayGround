Text Styling

How to use this page

  1. Type your text into the input box to start styling it.
  2. Change the font, size, weight, color, and spacing options.
  3. Watch the live preview and copy the CSS when you are happy with the result.
How to use this page:
  • Font Family (font-family): changes the typeface. Use it to switch between serif, sans-serif, and decorative styles.
  • Font Size (font-size): makes the text larger or smaller.
  • Font Weight (font-weight): controls boldness, from lighter to heavier text.
  • Font Style (font-style): makes the text normal, italic, or oblique.
  • Font Variant (font-variant): changes text presentation such as small caps.
  • Line Height (line-height): adjusts the spacing between lines of text.
  • Text Align (text-align): positions text left, right, center, or justified.
  • Text Decoration (text-decoration): adds underline, overline, or line-through effects.
  • Text Transform (text-transform): changes text to uppercase, lowercase, or capitalized form.
  • Letter Spacing (letter-spacing): increases or decreases space between letters.
  • Word Spacing (word-spacing): changes space between words.
  • Text Indent (text-indent): adds indentation to the first line of a paragraph.
  • Text Color (color): changes the text color.
  • Text Shadow X and Text Shadow Y (text-shadow): move the shadow horizontally and vertically.
  • Text Shadow Blur (text-shadow blur radius): softens the shadow effect.
  • Shadow Color (text-shadow color): sets the shadow color.
