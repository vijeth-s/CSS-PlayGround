Animation Generator

How to use this page

  1. Enter an animation name and timing details in the controls.
  2. Choose keyframe properties and values to build your animation.
  3. Review the generated CSS and copy it for your project.
How to use this page:
  • Animation Name (animation-name): gives the animation a custom identifier so it can be referenced in CSS.
  • Animation Duration (animation-duration): sets how long one cycle of the animation lasts.
  • Animation Timing Function (animation-timing-function): controls the speed curve, making the motion start fast, slow, or smoothly.
  • Animation Iteration Count (animation-iteration-count): defines how many times the animation repeats.
  • Animation Direction (animation-direction): determines whether the animation runs forward, backward, or alternates.
  • Animation Fill Mode (animation-fill-mode): defines how the element looks before and after the animation plays.
  • Transform (transform): changes the element's position, scale, rotate, or skew.
  • Opacity (opacity): makes the element fade in or out.
  • Background Color (background-color): changes the element's background during the animation.
  • Left Position (left): moves the element horizontally within its container.
  • Top Position (top): moves the element vertically within its container.
