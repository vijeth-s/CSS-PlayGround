# 📖 About

**CSS PlayGround** is an interactive web application designed to make learning CSS simple, engaging, and practical. It enables users to experiment with CSS properties through real-time visualization, helping them understand how different styles affect HTML elements without repeatedly editing code.

Whether you're a beginner exploring CSS fundamentals or a front-end developer prototyping UI components, CSS PlayGround provides an intuitive environment to learn, experiment, and generate reusable CSS code instantly.

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Vijeth-Shetty/CSS-PlayGround.git
```

### Navigate to the Project

```bash
cd CSS-PlayGround
```

### Run the Project

Simply open the **index.html** file in your preferred web browser.

No installation, build tools, or additional dependencies are required.
