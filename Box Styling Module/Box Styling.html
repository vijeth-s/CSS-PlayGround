Box Modeling

How to use this page

  1. Adjust the height, width, border, and shadow sliders to build your box.
  2. Use the color pickers to change the fill, border, and shadow colors.
  3. Preview the result and copy the generated CSS for your own project.
How to use this page:
  • Box Height (height): sets the box's vertical size. Use it to make the element taller or shorter.
  • Box Width (width): sets the box's horizontal size. Use it to make the element wider or narrower.
  • Color Opacity: controls how transparent the fill color is. Use it to make the box more subtle or more bold.
  • Border Radius (border-radius): rounds the corners of the box. Use it for softer, pill-like, or modern rounded shapes.
  • Border Opacity: controls how transparent the border is. Use it to make the border faint or vivid.
  • Border Thickness (border-width): sets how thick the border appears. Use it for thin or bold outlines.
  • Shadow X (horizontal offset): moves the shadow left or right. Positive values move it to the right, negative values move it to the left.
  • Shadow Y (vertical offset): moves the shadow up or down. Positive values move it downward, negative values move it upward.
  • Shadow Blur (blur-radius): controls how soft or sharp the shadow looks. Higher values create a softer shadow.
  • Spread Radius: changes the size of the shadow. Positive values make the shadow larger, negative values make it smaller.
  • Shadow Opacity: controls the transparency of the shadow. Use it to make the shadow lighter or darker.
  • Border Style (border-style): defines how the border appears, such as solid, dashed, dotted, or double.
  • Color (background-color): changes the main fill color of the box.
  • Border Color (border-color): changes the color of the border.
  • Shadow Color (box-shadow color): changes the color of the shadow.
  • Inset Shadow (inset): places the shadow inside the box instead of outside it, creating an inner glow or depth effect.
